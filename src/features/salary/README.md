# Salary

薪资周期、工资核算明细与发放记录。

## 核算边界

- 新工资单由服务端按已生效的版本化企业费率政策计算，浏览器提交的应发、个税、扣款合计和实发金额不会被采信。
- 计算采用人民币分的整数运算，并按居民个人工资薪金累计预扣法计算本期个税。
- 社保、公积金缴费基数和个人比例由企业薪资管理员配置；系统不会内置某个城市或年份的固定政策值。
- 已确认或已发放的计算工资单在 V1 中不可修改。历史手工工资单继续可读，不会被自动重算。

## 权限与隐私

- `salary.manage` 可维护薪资政策、预览核算和保存工资单。
- `payroll.read.self` / `salary.self` 只允许员工读取当前登录身份关联的本人工资单。
- 工资、社保和个税数据只保存在受 RLS 保护的数据库中，不进入 URL、本地存储或客户端公开环境变量。
- 薪资计算不新增密钥，正式环境复用现有 Supabase 服务端凭据。

## 上线要求

首次启用前必须先应用数据库迁移，再由有权限的薪资负责人录入、校验并激活费率政策。详细步骤见 `docs/deployment/payroll-calculation-rollout.md`。
