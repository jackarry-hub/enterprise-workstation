# QuantXY 事件响应

## Severity

P0：跨租户、数据丢失、审计被改、密钥泄露或全站不可用。P1：核心写入/登录/薪资/审批不可用。P2：局部功能降级且有安全替代。P3：低影响缺陷。P0 立即停流，P1 冻结发布。

## First response

确认时间窗、候选、环境和影响面；记录 request ID、就绪、错误率、连接/队列和外部状态。先保护数据与证据，不删除日志、不反复重试写操作、不在聊天粘贴秘密。

## Containment

按影响撤销凭据、启用 Agent kill switch、暂停目录/通知/AI 队列、限制 Canary 或回滚兼容镜像。数据库语义不兼容时按备份恢复，不手工删表或关闭 RLS。

## Evidence and review

保留脱敏时间线、决定、执行人、资源 ID、哈希和验证结果；恢复后核对七角色和核心旅程。72 小时内完成根因、修复、复发防护、负责人和期限，P0/P1 需独立复核。
