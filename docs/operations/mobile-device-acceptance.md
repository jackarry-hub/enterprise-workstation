# QuantXY 移动端商用验收

## 自动化矩阵

- 视口：360、375、390、430、768、1024、1366、1440、1920。
- 浏览器项目：Desktop Chrome、iPhone 13、Pixel 7、iPad Mini 仿真。
- 核心链路：登录后导航、通知、个人设置、AI 会话、Agent 快速创建、离线写入阻断、静态缓存边界与横向溢出。

## 上线前真实设备门禁

Staging 必须逐项保存截图、设备/系统/浏览器版本、操作人、时间和结果：

1. iPhone Safari：安装到主屏、登录回跳、AI 会话、通知已读、文件上传恢复。
2. Android Chrome：安装、弱网/离线提示、返回手势、软键盘输入、Agent 运行。
3. 飞书与微信内置浏览器：单点登录、下载/上传、外链回跳和安全提示。
4. Windows Chrome/Edge 与 macOS Safari/Chrome：桌面菜单、图表、键盘焦点、快速创建。
5. 所有设备验证退出登录后静态缓存不含业务响应、客户 PII、薪资、审批附件或 AI 内容。

任何真实设备失败、未执行或无证据均不得标记上线通过。
