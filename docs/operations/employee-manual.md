# QuantXY 员工使用手册

## Sign in

从企业入口使用飞书登录；首次使用确认企业和账号。发现所属部门、姓名或权限不正确时停止敏感操作并联系管理员，不共享验证码、Cookie 或下载链接。

## Daily workflow

首页只显示有权访问的工作。项目页创建里程碑/风险/成员，任务页创建任务、依赖、评论和验收；客户页管理跟进、联系人和商机；审批页提交费用/业务审批；知识、AI 和 Agent 只能使用已授权数据。移动端保持单手可操作，提交失败会保留明确状态，不能连续重复点击。

## Privacy and permissions

员工只能看本人或授权范围；薪资默认仅本人可见。文件下载链接会过期，禁止转发。AI 输出需复核，高风险工具调用必须人工确认。无权限、待配置和服务不可用会明确显示，不会提供示例数据。

## Getting help

记录发生时间、页面、操作和 request ID，避免截图包含薪资、手机号、令牌或客户隐私。通过工作台帮助/支持入口提交；P0/P1 事件同时通知管理员。
