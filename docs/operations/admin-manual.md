# QuantXY 管理员手册

## Initial setup

使用独立企业管理员完成飞书 OAuth、目录连接、组织/部门/岗位初始化和首批员工导入。随后配置角色权限、真实经理关系、薪资政策、审批模板、Storage、DeepSeek 预算与 Agent allowlist。任何“待配置”必须由业务负责人补齐，禁止用示例值替代。

## Daily operations

每日检查就绪、同步问题、通知重试、AI/Agent 队列、预算、失败上传和待审批权限。组织变更先解决冲突再发布；客户/项目/任务导入需原因、幂等键和逐行结果。请假考勤不在本期范围。

## Audit and export

导出需要独立权限、业务原因、水印、短有效期和审计。薪资、联系人、私档和文件按最小范围导出。管理员不能修改或删除审计事件，不能把日志/截图当数据导出渠道。

## Failure handling

出现跨租户、审计可变、数据丢失或密钥泄露立即按 P0 停流；外部服务失败不得回退 Mock。保留 request ID、候选提交、时间窗和脱敏证据，按事件响应手册升级。数据库迁移/恢复只能由获授权 Owner 执行。
