# 项目管理中心第一阶段实施计划

**目标：** 补齐项目动态、项目风险和文件关联数据模型，并严格依照桌面设计稿和移动端参考实现 `/projects`。

**技术边界：** Next.js 15 App Router、TypeScript、Tailwind CSS v4、Shadcn UI、Lucide React；前端只用 Mock，不创建详情路由。

## Task 1：数据扩展测试与 migration

- [ ] 先添加 migration 契约测试，覆盖三张表、关键外键、索引、RLS 和权限策略。
- [ ] 新增独立增量 migration，不改写已审核的基础 migration。
- [ ] 让项目动态保持 append-only；项目风险由管理员或项目负责人管理；文件关联保持同项目完整性。

## Task 2：TypeScript 与 Mock 契约

- [ ] 先扩展 Mock 一致性测试。
- [ ] 新增 `ProjectActivity`、`ProjectRisk`、`FileRelation` 及状态类型。
- [ ] 扩展项目列表视图字段、组合筛选函数、统计和里程碑提醒 Mock。

## Task 3：页面失败测试

- [ ] 先验证标题、四类统计、新建项目、搜索、筛选和项目列表均存在。
- [ ] 先验证搜索与组合筛选能改变结果，并提供清晰空状态。
- [ ] 确认没有详情路由或项目行跳转。

## Task 4：页面实现

- [ ] 启用 Sidebar 项目导航和路径选中态。
- [ ] 实现项目标题、统计卡、列表工具栏、桌面列表、右栏提醒与移动卡片。
- [ ] 实现移动底部导航和安全区域间距。
- [ ] 所有核心搜索、分组、筛选、重置和视图选中态可用。

## Task 5：验证与设计 QA

- [ ] 运行项目测试、全量测试、typecheck、lint、build。
- [ ] 用内置浏览器验证桌面原稿尺寸和移动参考尺寸。
- [ ] 截图后将原稿与实现截图一起进行 `view_image` 对比，至少检查文案、结构、颜色、字体、间距、图标、交互和响应式。
- [ ] 修复所有可见偏差，输出桌面与移动截图。
