# QuantXY 单文件工作站演示登录设计

## 目标

为 `quantxy-ai-workbench-fused.html` 增加一个与现有蓝白视觉语言一致的演示登录入口。登录用于控制是否进入工作站；进入后仍可通过右上角菜单切换查看身份。该功能不连接后端，也不宣称具备生产级安全能力。

## 范围

- 默认演示账号：`admin`
- 默认演示密码：`123456`
- 首次打开或退出后显示登录页
- 登录成功后进入现有决策驾驶舱
- 登录状态保存在独立的本机存储键中，刷新后保持登录
- 当前查看身份继续使用现有 `S.me`，与登录状态互不混用
- 右上角身份菜单保留现有成员切换，并增加分隔线和“退出登录”
- 退出只清除登录状态，不删除任务、客户、活动、决策或其他演示数据

## 交互与视觉

登录页使用全屏浅色背景与居中白色卡片，复用 QuantXY 标志、品牌蓝、圆角、阴影、输入框和按钮样式。卡片包含账号、密码、显示/隐藏密码、记住登录状态、登录按钮、错误提示和“演示环境”说明。

桌面端保持居中卡片；窄屏下卡片宽度随视口缩小，主要按钮保持可点击且不产生页面横向溢出。登录成功后不增加中间欢迎页，直接进入工作站。

## 状态与数据流

新增独立登录状态：

- `sessionStorage` 保存本次会话登录状态
- 勾选“记住登录状态”时改用 `localStorage`
- 启动时先检查登录状态；未登录只渲染登录页，不渲染工作站导航和内容
- 登录成功后清除错误、记录状态并渲染工作站
- 退出时同时清除两处登录状态并重新渲染登录页

登录凭据仅作为单文件演示常量存在。登录状态与现有 `qxy` 业务数据记录分离，避免退出时误删业务演示数据。

## 错误处理

- 账号或密码为空：提示“请输入账号和密码”
- 凭据不匹配：提示“账号或密码错误，请使用演示账号”
- 本机存储不可用：仍允许当前页面内登录，刷新后需要重新登录
- 连续点击登录时不重复触发跳转

## 验收与测试

- 清除登录状态后再次打开显示登录页，工作站内容不可见
- 错误账号或密码不会进入工作站，并显示错误提示
- `admin / 123456` 登录成功并进入决策驾驶舱
- 勾选记住登录后刷新仍保持登录
- 登录后可在右上角切换成员身份，无需再次输入密码
- 退出登录返回登录页，业务演示数据保持不变
- 桌面端和 390×844 窄屏均无整体横向溢出
- 既有客户、活动、决策及原工作站模块专项测试继续通过

## 非目标

- 不接入真实用户数据库、短信、验证码、单点登录或第三方 OAuth
- 不提供注册、找回密码、修改密码或用户管理后台
- 不把演示凭据作为生产环境安全方案
