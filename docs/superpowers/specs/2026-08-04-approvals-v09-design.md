# 企业工作站 Demo V0.9：审批中心设计说明

## 业务流程

员工发起请假、报销、采购或合同申请，系统按固定步骤流转到当前负责人；负责人查看申请信息和历史记录后同意或拒绝。V0.9 不提供流程设计器、条件分支或会签。

## 数据模型

- `approvals`：稳定的审批单主表，关联组织、申请员工和当前负责人，保存类型、标题、摘要、结构化申请内容、当前步骤与状态。
- `approval_steps`：固定流程节点，保存顺序、负责人、节点状态和处理时间。
- `approval_actions`：不可变审批记录，保存提交、同意、拒绝与备注事件。
- 三张表均使用公共 UUID、组织隔离、软删除或不可变历史策略、索引与 RLS；不创建重复的业务主表。

## 页面

- `/approvals`：标题区、待审批/我发起/已通过/已拒绝统计，状态 Tab、类型筛选、搜索和审批卡片列表。
- `/approvals/[id]`：申请摘要、结构化申请内容、固定审批流程、审批记录；待审批单支持同意和拒绝，使用复用 `Dialog` 完成确认和本地演示状态更新。

桌面布局参考既有 `11_企业工作站_审批中心.png`，移动端参考已有审批中心卡片稿；保持现有 Workspace Layout 与玻璃拟态组件体系。

## 验收

- 四类审批和四种统计完整，列表筛选可用。
- 每条审批可进入详情，节点和历史清晰可见。
- 同意/拒绝操作有确认反馈，不引入复杂流程引擎。
- 桌面和移动端无横向溢出，相关测试与视觉 QA 通过。
