# 企业工作站 Demo V0.9：考勤管理设计说明

## 目标与边界

本模块为企业管理者和 HR 提供当日团队考勤总览，形成“员工档案 → 考勤记录 → 管理查看”的稳定链路。本轮交付 `/attendance` 的统计、记录、轻量月度趋势和异常提醒，不开发定位打卡、排班引擎、考勤规则配置或独立统计分析子系统。

## 角色与场景

- 老板、管理员、HR：查看组织内员工的考勤统计与明细。
- 部门负责人：未来可按授权范围查看本部门；V0.9 先保留组织级数据结构。
- 普通员工：数据库权限为后续“查看本人考勤”留出空间，本页仍是管理视图。

## 数据模型

复用 `organizations`、`employee_profiles`、既有角色与权限模型，新增稳定核心表 `attendance`，避免创建重复的 `attendance_records`。

- 组织、员工、考勤日期组成未删除记录的业务唯一键。
- 记录计划上下班时间、实际签到签退时间、状态、迟到/早退分钟数、来源与备注。
- 状态固定为 `normal`、`late`、`early_leave`、`leave`。
- 来源固定为 `manual`、`import`、`device`，本版本不保存定位字段。
- 使用软删除、更新时间触发器、跨组织员工关系守卫和 RLS。
- 组织成员可读取；老板、管理员、HR 可新增或更新；不开放物理删除策略。

## 页面结构

1. 顶部欢迎区：页面标题、说明、当前日期和“演示数据”标识。
2. 考勤统计：今日出勤、迟到人数、请假人数、出勤率，复用 `DataCard`。
3. 考勤记录卡片：搜索、日期、部门、状态筛选；桌面使用 `Table`，移动端转换为玻璃卡片列表。
4. 月度出勤趋势：使用现有图表能力展示工作日出勤率、迟到和请假变化，不扩展为分析模块。
5. 异常提醒：从同一批考勤记录派生迟到、早退、未签退和请假提醒，不创建重复异常表。
6. 空状态与数据来源提示。

视觉延续现有企业工作站的白蓝渐变、半透明玻璃卡片、大圆角、柔和阴影和留白。桌面参考 `14_企业工作站_数据分析.png` 中实际的考勤管理页面；移动端参考既有考勤设计稿的卡片密度与层次，但不引入其个人定位打卡功能。

## Mock 数据

页面默认使用 2026-08-04 的演示数据：128 名应出勤员工，119 名已出勤，6 名迟到，3 名请假，出勤率 92.6%。列表提供跨部门、跨状态的代表性记录，筛选统计由纯函数处理，方便后续替换 Supabase 查询结果。

## 验收

- `/attendance` 可从 Sidebar 访问。
- 统计、搜索、日期、部门和状态筛选可用。
- 月度趋势与异常提醒均由同一考勤数据模型派生。
- 四种状态一眼可辨，桌面与 430px 移动端无横向溢出。
- 数据库 migration 契约、数据选择器、组件交互和浏览器主流程测试通过。
- 与 UI 参考图完成同视口视觉对照，`design-qa.md` 最终结果为 `passed`。
