# 企业工作站 V0.9 导航页面完整化设计

## 目标

在不连接飞书、不连接真实数据库、不重构现有模块的前提下，补齐任务管理、数据分析、知识库、客户管理并完善系统设置，使当前 Sidebar 中所有业务导航均可访问、可交互、可截图演示。

开发顺序固定为：

1. 任务管理 `/tasks`
2. 数据分析 `/analytics`
3. 知识库 `/knowledge`
4. 客户管理 `/customers`
5. 系统设置 `/settings`

每个模块完成自身测试后再进入下一模块。

## 范围边界

本阶段包含：

- 五个指定路由的完整页面与基础响应式。
- 搜索、筛选、状态切换、详情查看、Mock 新建或设置保存等基础交互。
- 任务管理与现有项目任务、本地项目仓库的统一数据闭环。
- 数据分析从项目、任务和员工 Mock 数据派生统计。
- Sidebar 中任务管理、知识库、客户管理和数据分析改为可访问。
- 桌面端与移动端截图验收。

本阶段不包含：

- 飞书、Supabase、真实认证、真实数据库、文件存储和权限系统。
- 高级销售漏斗、合同回款、知识库编辑器、文档版本、数据导出服务。
- 对 Dashboard、工作中心、项目管理、项目详情、活动推进、组织人事、考勤、审批和薪资页面的视觉重写。

## 共享架构

采用独立 Feature 模块与共享 Mock 查询层：

```text
src/features/
├─ tasks/        # 在现有工作中心 feature 内增加任务管理
├─ analytics/    # 新增分析模型、选择器和页面组件
├─ knowledge/    # 新增知识文档 Mock 与页面组件
├─ customers/    # 新增客户 Mock 与页面组件
└─ settings/     # 重构现有设置页面内容映射，不改变全局视觉
```

继续复用 `Workspace Layout`、`Sidebar`、`Header`、`GlassCard`、`DataCard`、`PageHeader`、`StatusBadge`、`ProgressBar`、`Table`、`Dialog`、`Tabs` 和现有图表封装。

各组件不直接解析 `localStorage`。任务与分析通过共享选择器合并默认项目详情和浏览器本地项目覆盖记录；知识库和客户管理使用独立轻量 Mock 数据。

## 任务管理 `/tasks`

### 数据来源

- 复用 `ProjectTask`、`ProjectDetailData`、`MemberSummary` 和项目 Mock 数据。
- 合并默认项目详情与 `enterprise-workspace.projects.v1` 中的本地覆盖记录。
- 同 ID 本地项目覆盖默认项目；浏览器新建项目直接加入任务汇总。
- 不创建第二套任务状态和持久化键。
- 当前项目演示成员沿用项目列表已有 viewer 关系；“我的任务”包含该成员负责或发布的任务。

### 状态映射

| 页面状态 | 领域状态 |
| --- | --- |
| 待开始 | `backlog`、`todo` |
| 进行中 | `in_progress`、`in_review` |
| 已完成 | `done` |
| 已取消 | `cancelled` |

`cancelled` 显示但不进入完成率分母。

### 设计稿内容映射

沿用 `06_任务管理` 的顶部横幅、三列卡片、第二行协作/日程/动态卡和底部入口区：

- “今日待办”区域展示到期任务和总体摘要。
- “我的任务”区域展示状态 Tab 和主要任务列表。
- “快捷操作”区域承载项目、负责人、优先级筛选和重置操作，保持原图宫格式控件视觉。
- “团队协作”区域展示负责人任务分布。
- “日程安排”区域展示最近截止时间线。
- “最近动态”区域展示任务与项目动态。
- 底部入口区作为全部任务、待开始、进行中、已完成等状态快捷入口。

关键词搜索位于设计稿顶部搜索区域。点击任务打开详情 `Dialog`，展示任务名称、描述、所属项目、负责人、截止时间、优先级和状态。详情内允许切换待开始、进行中、已完成，复用现有项目任务更新函数和项目进度计算，并写回项目仓库。

## 数据分析 `/analytics`

### 数据来源

- 项目数量、状态和健康度来自有效项目详情。
- 任务总量、完成率和状态分布来自有效任务。
- 员工执行情况由任务负责人聚合。
- 企业趋势使用基于当前有效数据的确定性 Mock 时间序列，不在组件中写散落统计常量。

### 设计稿内容映射

严格沿用 `14_数据分析` 的顶部筛选、四张统计卡、左侧大表、中部趋势卡和右侧提醒卡布局：

- 原日期与部门筛选映射为时间范围和部门筛选。
- 四张统计卡映射为项目总数、进行中项目、任务完成率和活跃员工。
- 左侧大表映射为员工执行情况。
- 中部趋势图映射为项目推进率与任务完成率。
- 右侧异常提醒映射为项目风险与延期提醒。
- 原日历区域映射为项目交付日历。
- 原请假审批分布映射为项目健康度分布及重点项目列表。

时间范围支持本月、季度和半年切换，部门支持全部及现有部门。筛选后统计、表格和图表同步更新。

## 知识库 `/knowledge`

### 数据模型

轻量模型包含：分类、文档、文件类型、作者、更新时间、浏览量、标签、摘要和知识动态。不实现正文编辑与真实文件。

### 页面映射与交互

严格沿用 `12_知识库`：

- 顶部搜索横幅与原图文件夹视觉区。
- 六个分类入口。
- 最近查看、热门文档、知识库动态三列卡片。
- 文档文件夹、标签云、知识库概览三列卡片。

搜索支持标题、摘要和标签；分类卡和标签支持筛选；“查看全部”切换相应数据范围；点击文档打开预览 `Dialog`，显示摘要、分类、作者、标签、更新时间和浏览量。无结果时显示重置操作。

## 客户管理 `/customers`

### 数据模型

轻量模型包含客户、联系人、负责人、行业、来源、跟进状态、最近联系、成交进度、关联项目、提醒和客户动态。不实现合同、回款和销售自动化。

### 页面映射与交互

严格沿用 `13_客户管理`：

- 顶部标题与新建客户按钮。
- 四张客户统计卡。
- 左侧客户列表及筛选。
- 右侧销售漏斗、待跟进提醒和客户动态。
- 底部来源分布、行业分布和地区分布。

客户列表展示客户名称、联系人、来源、跟进状态、负责人、最后联系和成交进度。搜索和状态、来源、行业筛选实时生效。点击客户打开详情 `Dialog`，展示企业信息、联系人、关联项目和跟进记录；关联项目跳转现有项目详情。新建客户使用 Mock `Dialog`，提交后只在当前页面会话中增加并同步统计。

## 系统设置 `/settings`

### 页面映射

严格沿用 `15_系统设置` 的外层大卡、左侧垂直设置导航、顶部保存区、三列设置卡和底部快捷配置区。

V0.9 只提供三个正式入口：

- 企业信息
- 个人设置
- 通知设置

左侧导航使用设计稿的垂直结构；未纳入本阶段的组织权限、安全规则、审批配置、考勤规则、薪资规则、备份和日志不显示为可点击占位。

企业信息包含名称、简称、Logo、时区、语言、成立日期和工作周。个人设置包含头像、姓名、邮箱和密码输入。通知设置包含站内通知、邮件通知、每日摘要和系统偏好。

“保存”将当前表单写入浏览器会话并显示成功状态；“取消”恢复本次进入页面时的值。Logo 和头像按钮打开本地图片选择，只接受图片类型并即时预览；无效文件显示错误，不上传服务器。

## 导航与基础交互

`/tasks`、`/knowledge`、`/customers`、`/analytics` 的 `navigationItems.available` 改为 `true`。所有新页面中的可见按钮必须具备行为：导航、搜索、筛选、重置、打开详情、新建 Mock 数据、切换状态、保存或取消。不得保留无反馈的装饰按钮。

全局 Header 和已完成模块中原有的未实现按钮不属于本阶段重构范围。

## 响应式

- 桌面端以设计稿 16:9 信息密度和卡片占比为基准。
- 大表区域在移动端转换为卡片，不压缩成不可读密集表格。
- 多列布局按设计稿阅读顺序纵向排列。
- 搜索和筛选控件在移动端占满宽度。
- Dialog 最大高度不超过视口并允许内容滚动。
- 430 × 932 视口不得出现页面级横向滚动。

## 错误与空状态

- 本地项目记录损坏：忽略损坏覆盖并继续使用默认 Mock。
- 任务状态保存失败：保留原状态并显示保存失败反馈。
- 搜索筛选为空：显示对应模块空状态与重置按钮。
- 新建客户字段缺失：Dialog 保持打开并显示字段错误。
- 图片类型无效：不创建预览 URL并显示错误。
- 图表数据为空：显示同尺寸空卡，避免页面结构跳动。

## 架构一致性

任务管理与数据分析消费现有项目聚合，不创建第二套项目或任务模型；知识库和客户管理在各自 Feature 内保持轻量 Mock；设置继续使用现有 Feature。所有新增页面通过现有 Workspace Layout 渲染，不修改全局 UI 体系。未来接入真实数据时，只替换各 Feature 的数据适配层，不重写页面组件。
