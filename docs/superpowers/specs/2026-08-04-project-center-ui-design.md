# 项目管理中心 UI 设计规格

## 范围与基准

本阶段只实现 `/projects`。不创建 `/projects/[id]`，不开发项目详情、看板、甘特图、文件或日报页面。

- 桌面端唯一视觉基准：`C:\Windows\TEMP\enterprise-workstation-designs\04_企业工作站_项目管理中心.png`
- 移动端视觉基准：用户提供的五张企业工作站移动稿，重点继承白蓝背景、半透明大圆角卡片、彩色渐变图标、单列信息流、紧凑顶部栏和固定底部导航。
- 现有 QuantXY 透明 Logo、WorkspaceShell、Sidebar、Header、GlassCard、DataCard、StatusBadge、Progress 继续复用。

## 页面信息与允许文案

首屏可见文案严格限制为设计稿和用户需求中的内容：

- 标题：项目管理中心
- 副标题：全面掌控项目进展，确保每个项目按时高质量交付
- 主操作：新建项目
- 统计：全部项目、进行中、已完成、延期风险
- 列表分组：全部项目、我负责的、我参与的、我关注的、已完成
- 视图切换：概览、看板、甘特图、成员、文件
- 筛选：项目状态、优先级、负责人、截止日期、搜索项目名称、重置筛选
- 右侧信息：里程碑提醒、项目日历

不新增营销口号、说明性徽标或设计稿之外的首屏装饰文案。

## 设计系统

### 色彩

- 页面背景：真正的白色与极浅蓝网格渐变，不改成米白或暖灰。
- 主色：现有 `primary` 蓝。
- 成功：现有 `success` 绿；警告：现有 `warning` 橙；风险：现有 `destructive` 红；辅助强调：`chart-3` 紫。
- 卡片：`glass` 半透明白，`glass-border` 淡蓝边框，柔和蓝灰投影。

### 字体与密度

- 页面标题：桌面 30px 左右、移动 24px，600 字重。
- 正文与控制：14px；辅助信息 12px；项目名称 15–16px、600 字重。
- 桌面列表保持原稿的信息密度；移动端不压缩成横向表格，转换为可触控的项目卡片。

### 几何与层级

- 玻璃卡片使用 16–24px 圆角；统计图标为圆形或圆角渐变底。
- 页面最大宽度沿用工作站 1680px 级画布；桌面主列表与右侧提醒栏约 3:1。
- 统计卡桌面四列，移动端两列。
- 筛选区桌面单行；移动端横向滚动并保留搜索框全宽。

### 图标

全部使用项目既有 Lucide React，保持 1.8–2px 线宽和当前组件尺寸。项目、进度、完成、风险分别使用 FolderKanban、LoaderCircle、CircleCheckBig、TriangleAlert。不得用 emoji、CSS 图形或手绘 SVG 代替。

## 核心交互

- 搜索按项目名称、项目编码、负责人匹配并即时过滤。
- 状态、优先级、负责人、截止日期筛选可组合使用。
- 顶部分组标签可切换“全部/负责/参与/关注/已完成”。
- 重置筛选恢复全部项目和默认分组。
- 视图切换仅在当前页呈现选中态；本阶段不创建其他页面。
- “新建项目”按钮保留为管理员入口，本阶段只提供可见按钮，不展开创建表单。
- 项目行不链接到详情页，避免越过当前开发范围。

## 响应式规则

- `lg` 以上：固定 Sidebar、Header、四统计卡、项目列表和右侧提醒栏。
- `md`：隐藏右侧提醒栏，列表保持表格式信息区。
- `sm` 以下：抽屉 Sidebar、紧凑 Header、2×2 统计卡、项目卡片列表、固定底部导航；页面增加底部安全间距。
- 最小支持宽度 320px；不得出现横向页面溢出、遮挡主操作或底部导航覆盖内容。

## 组件边界

- `ProjectsPage`：服务端页面组合，读取本地 Mock。
- `ProjectsWorkspace`：客户端筛选状态和页面组合。
- `ProjectStats`：统计卡组。
- `ProjectFilters`：分组、视图、搜索和选择器。
- `ProjectList`：桌面列表与移动卡片双视图。
- `ProjectAside`：里程碑提醒和项目日历，仅桌面展示。
- `ProjectMobileNav`：移动端底部导航，仅当前 `/projects` 页面渲染。
