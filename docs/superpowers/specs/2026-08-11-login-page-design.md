# 量子星河登录页参考图改版说明

## 目标

在不改变第一阶段身份系统的前提下，将 `/login` 改造成参考图所示的浅色科技感企业登录页。页面只供量子星河内部使用，继续以飞书作为当前唯一登录入口，同时保留后端 OAuth Provider 的扩展能力。

## 视觉结构

桌面端采用左右分区布局：

- 左上展示量子星河品牌标识和“AI 企业大脑”。
- 左侧主标题使用“高效协同 · 智领未来”，配一行简短说明。
- 左侧下方展示“项目协同、任务交付、组织协作”三项能力，替代参考图中的考勤、薪资和审批内容。
- 中部使用独立的蓝白半透明科技主视觉，形成参考图的空间层次。
- 右侧使用大圆角磨砂登录卡，包含登录标题、内部使用说明、错误提示、唯一飞书登录按钮和安全说明。

整体延续现有白色、浅蓝渐变、玻璃拟态、大圆角风格。页面避免传统 OA 后台感，不出现账号密码、短信验证码或上下班打卡暗示。

## 登录行为

- 保留现有 `signInWithFeishu` 服务端登录动作。
- 页面只显示一个清晰的“使用飞书登录”按钮。
- 已登录用户仍按现有角色和权限跳转到对应工作台。
- 登录失败时只展示已批准的通俗提示，不泄露 OAuth、数据库或内部标识信息。
- 本次仅调整登录页视觉和文案，不新增其他登录 Provider，不修改用户、权限或组织身份数据模型。

## 响应式布局

- 大屏：品牌与能力说明、科技主视觉、登录卡共同形成横向构图。
- 中屏：缩小主视觉并压缩左右间距，保持登录卡优先可见。
- 手机：切换为纵向布局，保留品牌、标题和登录卡；能力列表缩短或隐藏，主视觉弱化，保证首屏即可完成登录。

## 无障碍与可用性

- 保持页面单一主标题、明确按钮名称和错误提示的 `role="alert"`。
- 按钮具备键盘焦点状态，并满足浅色背景下的可读性。
- 品牌与装饰图片使用准确替代文本或空替代文本，避免重复朗读。
- 不使用不可操作的输入框或假登录选项。

## 验收标准

- 在参考图的桌面比例下，页面结构、留白、玻璃卡片、蓝白色调和视觉重心明显一致。
- 页面只存在一个登录按钮，且能继续触发现有飞书 OAuth 流程。
- 不出现密码、验证码、考勤打卡、薪资或审批入口。
- 登录组件测试、类型检查、代码检查和生产构建通过。
- 完成同尺寸视觉对照检查，并记录在 `design-qa.md`，最终结果为 `passed`。
