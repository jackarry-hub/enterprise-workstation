# 项目协同中心页面规划

本规划定义后续 UI 阶段的信息结构与数据契约。本阶段不创建页面路由或组件。

## `/projects` 项目列表

### 页面目标

让企业管理者快速查看项目组合，让项目成员快速进入自己参与的项目。默认按“进行中优先、截止日期升序”排列。

### 列表字段

| 字段 | 数据来源 | 说明 |
| --- | --- | --- |
| 项目名称 | `Project.name` | 同时展示项目编码和关联企业目标摘要 |
| 负责人 | `Project.ownerMemberId` | 映射企业成员姓名与头像 |
| 成员 | `ProjectMember[]` | 展示前若干头像与总人数 |
| 进度 | `Project.progress` | 0–100 的项目整体进度 |
| 状态 | `Project.status` | 规划中、进行中、已暂停、已完成、已取消 |
| 截止日期 | `Project.dueDate` | 临期与逾期状态由日期和项目状态派生 |

### 交互与权限

- 所有人只看到 RLS 允许的项目；老板和管理员可查看企业全部项目。
- 仅管理员显示“新建项目”入口。
- 当前 `/projects` 第一阶段不让项目行跳转，避免提前开发详情；后续详情阶段再接入 `/projects/[id]`。
- 搜索与筛选先使用页面本地状态和 Mock 数据，接入 Supabase 后再通过 URL 查询参数保存。
- 首期规划的筛选项：关键词、状态、健康度、负责人、截止日期。

## `/projects/[id]` 项目详情

详情页共享项目抬头区：名称、编码、负责人、成员、状态、健康度、进度、起止日期和关联企业目标。编辑入口仅管理员、项目负责人和项目管理员可见。

### Tab 1：概览

- 项目说明、目标对齐、关键指标和时间范围。
- 项目健康度、整体进度、任务完成情况、里程碑完成情况。
- 最近动态、即将到期任务、当前阻塞与最新日报摘要。

### Tab 2：里程碑

- 按时间或排序展示里程碑名称、负责人、状态、进度和截止日期。
- 项目负责人/管理员可新增、编辑、排序和完成里程碑。

### Tab 3：任务

- 支持列表/看板视图的后续扩展，首期数据契约共用 `ProjectTask`。
- 展示任务、执行人、里程碑、优先级、状态、进度和截止日期。
- 项目负责人/管理员管理任务；成员只执行分配给自己的任务。

### Tab 4：甘特图

- 时间轴数据来自项目、里程碑和任务的开始/截止日期。
- 支持父子任务和里程碑分组；无日期任务进入“未排期”区域。
- 本阶段不选定具体甘特图库。

### Tab 5：文件

- 展示项目文件和任务附件，字段包括文件名、类型、大小、上传人和上传时间。
- 项目成员可上传，上传者或项目管理者可管理；查看者只读。

### Tab 6：日报

- 按日期倒序聚合成员日报，展示今日总结、下一步、阻塞问题和所需支持。
- 项目成员提交自己的日报；项目负责人/管理员可查看全部并管理异常内容。

### Tab 7：复盘

- 项目完成后聚合目标达成、里程碑、任务、延期、日报阻塞和文件沉淀。
- 复盘正文、结论和后续行动项的数据表暂不在本阶段创建，待 UI 与业务流程确认后单独设计，避免提前锁死字段。

## 路由与状态约定

- `[id]` 使用项目 `publicId`，不暴露数据库 bigint 主键。
- 无访问权限按未找到处理，避免泄露项目是否存在；有权限但项目不存在进入统一 404。
- Tab 使用 `?tab=overview|milestones|tasks|gantt|files|reports|retrospective`，默认 `overview`。
- 加载、空数据、失败、无权限和软删除项目需要独立状态，具体视觉由后续 UI 设计稿决定。
